# Priya's Expense Summary & Analysis

## 📌 Project Overview
This project focuses on analyzing Priya's personal expenses using Microsoft Excel. The objective is to understand spending patterns, identify major expense categories, track monthly expenses, and suggest ways to reduce unnecessary spending.

The project uses Excel formulas, data validation, conditional logic, and charts to transform raw expense data into meaningful insights.

## 📂 Dataset Information
- **Dataset:** Priya's Expense Data
- **Total Records:** 50 Transactions
- **Time Period:** October 2021 – December 2021
- **Total Expense:** ₹57,045.27
- **Tool Used:** Microsoft Excel

### Dataset Columns
- Date
- Items
- Expense
- Category
- Cost Type

## 🎯 Project Objectives
1. Count transactions for online shopping, ordering food, and gifts.
2. Calculate total expenses for each distinct item.
3. Arrange item-wise expenses in descending order.
4. Visualize item-wise expenses as a percentage of total expenses, excluding trip expenses.
5. Analyze monthly expense patterns over three months.
6. Categorize expenses into Essentials and Non-essentials.
7. Identify expenses as Over Budget or Within Budget.
8. Provide recommendations to reduce unnecessary expenses.
